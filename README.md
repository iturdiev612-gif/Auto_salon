# TURDIEV AUTO 3.0

Третья версия проекта автосалона. Главное изменение: вход, регистрация и админ-панель теперь открываются как **отдельные страницы**, а не как секции/модальные окна внутри главной страницы.

## Страницы
- `index.html` — главная, каталог 30 демонстрационных автомобилей, поиск/фильтры, карточки, избранное, корзина и форма бронирования.
- `auth.html?mode=login` — отдельная страница **Sign in**.
- `auth.html?mode=signup` — отдельная страница **Sign up**.
- `admin.html` — отдельная защищённая рабочая панель администратора: статистика, добавление/редактирование/удаление автомобилей, список заявок из Supabase.
- `supabase/schema.sql` — таблицы, триггер профиля и политики безопасности.
- `supabase/seed-cars.sql` — примеры 30 автомобилей.

## Перед запуском

1. Создайте проект в Supabase.
2. Откройте `supabase/schema.sql`, скопируйте весь SQL в Supabase → SQL Editor → New query и нажмите Run.
3. Откройте `supabase-config.js` и вставьте свой Project URL и **publishable/anon key**. Не вставляйте `service_role` или secret key в браузерный код.
4. Выполните `supabase/seed-cars.sql`, чтобы заполнить каталог 30 демонстрационными автомобилями. Эти записи являются примерами — проверьте характеристики и цены перед реальным использованием.
5. В Supabase → Authentication → URL Configuration задайте Site URL и Redirect URLs для локального адреса разработки и адреса сайта на Vercel.
6. Запустите проект через локальный веб-сервер (например, расширение Live Server в VS Code), а не открытием HTML-файлов напрямую.
7. Зарегистрируйтесь на `auth.html?mode=signup`. Если включено подтверждение email, подтвердите адрес из письма и затем войдите.
8. Чтобы назначить собственный аккаунт администратором, найдите его UUID в Supabase → Authentication → Users. В SQL Editor выполните запрос, подставив UUID:

   ```sql
   update public.profiles
   set role = 'admin'
   where id = 'ВСТАВЬТЕ-UUID-АККАУНТА';
   ```

   Не добавляйте в публичную форму возможность выбирать роль `admin`. Роль выдаётся только владельцем проекта.
9. Разместите проект на Vercel. Импортируйте репозиторий, а в Supabase добавьте домен Vercel в Redirect URLs.

## Как работает вход и панель

- Кнопки `Sign in` и `Sign up` в шапке ведут на отдельную страницу авторизации.
- Значок человечка в шапке и плавающий значок в правом нижнем углу ведут на `admin.html`.
- Без входа панель предложит авторизоваться. Вошедший пользователь без роли `admin` увидит сообщение о недостатке прав.
- Администратор может создавать, редактировать и удалять автомобили. Изменения применяются к базе Supabase, если SQL-схема и RLS настроены.
- В панели показываются заявки, сохранённые в таблице `bookings`.
- Бронирование на главной открывает WhatsApp с заполненным текстом для номера `+996 999 42 54 53`. WhatsApp не отправляет сообщение автоматически: пользователь должен нажать кнопку отправки в WhatsApp.

## Что важно знать

- Это подготовленный проект, но он не подключён к вашему аккаунту Supabase и не опубликован в Vercel автоматически. Для реальной авторизации и базы нужно выполнить шаги настройки выше.
- Каталог может показывать встроенные демонстрационные данные, если Supabase не настроен.
- Избранное и корзина пока хранятся в localStorage конкретного браузера, а не синхронизируются между устройствами.
- Переключение языка в этой версии частичное, а не полный перевод всего контента.
- Платёжный шлюз, OAuth Google/GitHub, Cloudinary, email/Telegram-уведомления, рейтинги и чат-бот пока не реализованы.
- Никогда не размещайте секретные ключи Supabase в `script.js`, `auth-page.js`, `admin-page.js` или других клиентских файлах.


## Обновление 3.1 — запуск без настройки Supabase

Чтобы можно было проверить интерфейс сразу, добавлен локальный демонстрационный режим: регистрация и вход сохраняют тестовый аккаунт в localStorage этого браузера. Это НЕ серверная и НЕ защищённая авторизация; для реального сайта подключите Supabase.

Демо-доступ к админ-панели: `admin@turdiev.auto` / `Admin123!`. Не используйте этот пароль в опубликованном реальном проекте. В локальном режиме автомобили, добавленные/изменённые/удалённые администратором, хранятся только в браузере.

Добавлены отдельные страницы `favorites.html` и `cart.html`. Нажатие на сердце добавляет машину в избранное и открывает страницу избранного; нажатие на добавление в корзину открывает отдельную страницу корзины. Данные списков сохраняются в localStorage текущего браузера.
